# 压片 LiteShot

电商卖家的**商品图批量处理**小工具：拖入一批图片（或整个文件夹），统一尺寸、压缩体积、加水印、批量改名，最后一键打包 ZIP。

**纯浏览器本地运行，图片不会上传到任何服务器。** 没有账号、没有 API key、不联网（页面只加载本仓库自带的文件）。

在线使用：https://yguodong627-star.github.io/vibe-liteshot/

## 适合谁
- 淘宝 / 天猫 / 拼多多 / Etsy / Amazon / Shopify 的个人卖家和小团队运营
- 每次上新要处理几十张图：尺寸不一、体积太大、要打水印、文件名乱

## 典型场景
1. 手机拍的 3000×2000 原图，要变成淘宝 1:1 主图（补白，不变形），再压到 3MB 以内
2. 一批图要统一加店铺名水印或 Logo，又不想一张张开 PS
3. 上 Etsy 前，把图改成 2000px 以上并控制在 1MB 左右，避免慢网上传失败
4. 把 `IMG_0412.JPG` 这类文件批量改成 `店名_款号_01.jpg`

## 功能
- **导入**：多选图片、选择文件夹、直接拖拽文件夹（保留子目录读取）
- **尺寸**：正方形补白（颜色可改/透明 PNG）、等比缩小、居中裁切、不改尺寸；内置平台预设（见下文核对状态）；默认小图不放大
- **压缩**：JPG / WebP / PNG / 保持原格式；质量滑块；**单张体积上限（KB）**自动找合适质量；列表与底栏显示压缩前后体积和百分比；预览窗并排对比原图与处理后
- **水印**：文字水印（大小、透明度、颜色、9 个位置、斜铺满屏）、图片 Logo 水印（宽度占比、透明度、位置）
- **重命名**：模板 `{name}` 原名、`{n}` 序号、`{w}x{h}` 尺寸、`{date}` 日期，可设起始序号与位数，自动处理重名与非法字符，实时预览
- **打包**：ZIP 下载（JSZip，已随仓库放在 `vendor/`，不依赖 CDN）
- **不卡页面**：处理放在 Web Worker 里并行进行；浏览器不支持（如直接双击 `index.html` 以 file:// 打开）时自动退回主线程分批处理
- 压缩时会去掉相机 EXIF（含拍摄地点等隐私信息）

## 完全免费
没有任何功能锁和用量限制：单次处理张数不限，尺寸 / 压缩 / 水印 / 重命名 / ZIP 全部可用，可保存常用预设并一键套用（存在本机浏览器）。图片只在你的浏览器里处理，不上传。

## 平台尺寸预设：核对状态（2026-10-18 查阅公开资料）
| 预设 | 状态 | 依据 |
|---|---|---|
| 淘宝 1:1 主图 1440×1440 | 已核对 | 淘宝商品主图要求整理资料（推荐 1440×1440 及以上；800×800 为早期建议）、淘宝开放平台上传规则公告（建议宽度 1440，单文件 ≤20MB） |
| 淘宝 3:4 主图 1440×1920 | 已核对 | 同上 |
| 淘宝详情页宽 750 | 部分核对 | 资料写宽度 620–1500px、单张高 ≤2000px、≤3MB；750 为常用值，请自行核对 |
| Amazon 主图长边 1600 | 已核对 | 长边 ≥1000px 可启用放大镜，1600+ 更佳；白底 / 占比 85% 等要求需自行把关 |
| Amazon 白底方图 2000×2000 | 行业惯例 | 非官方硬性要求 |
| Shopify 方图 2048×2048 | 已核对 | Shopify 官方博客：方形商品图 2048×2048，上限 5000×5000 / 20MB |
| Etsy 宽高 ≥2000px、首图 ≥635px | 已核对 | Etsy 帮助中心；透明 PNG 会显示为黑色，建议用 JPG |
| Etsy 4:3（2000×1500） | 比例未核对 | 帮助页只写首图用横图或方图，未写 4:3，请自行核对 |

各平台规则会更新，上传前请以商家后台为准。

## 已知限制
- 不支持 HEIC / TIFF / SVG；动图 GIF 只保留第一帧
- 不做抠图、不检测“纯白背景”“主体占比”
- 单张超大图（几千万像素）在低端手机上可能内存不足
- 直接 `file://` 打开可用，但会退回主线程处理，大批量时不如在线版流畅

## 本地使用
下载仓库，直接打开 `index.html` 即可；或在目录里运行 `python3 -m http.server` 再访问。
